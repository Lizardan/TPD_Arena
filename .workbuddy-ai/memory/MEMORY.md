# TPD Arena — долговременные заметки проекта

Telegram-бот групповых боёв с GIF-рендером. Всё в одном Cloudflare Worker
(бесплатный тариф): вебхук → симуляция → рендер без canvas/DOM → gifenc.

## Жёсткие ограничения

- **~10 мс CPU на запрос** (Cloudflare Workers free). Это главный фактор всех
  решений по рендеру. Текущий профиль `FREE_PROFILE`: 136×102, 12 fps, до 36
  кадров; worst case по 40 боям из диапазонов бота — 7.6 мс одиночно / 9.3 мс
  под нагрузкой.
- Стоимость рендера ∝ число кадров × площадь холста (~0.25 мс/кадр при 136×102).
  `gifenc` обходит **все** пиксели каждого кадра независимо от дельты, поэтому
  дельта-кадры экономят размер файла, но не время.
- Замеры делать через `min` нескольких одиночных вызовов **после прогрева**
  (`test/sweep.mjs` печатает `best` и `load`). Первый вызов врёт втрое (JIT),
  серия подряд — вдвое (GC), замер после принудительного `global.gc()` — тоже
  втрое (опустошённое молодое поколение).

## Команды и кнопки бота (UX)

- В меню команд Telegram **ровно одна** команда — `/arena`. Всё остальное кнопки.
- Меню ставится дважды: CI-шаг `setMyCommands` + ленивый `syncCommands()` в
  воркере (один раз на изолят). Второе — самолечение после правок в BotFather.
- Карточка арены несёт **inline**-кнопки: «⚔️ Выйти против X» (`style: 'success'`)
  и «🛑 Офнуть все арены в чате» (`style: 'danger'`, `callback_data: o|<chatId>`).
- Нижняя клавиатура («⚔️ Выйти на арену», `is_persistent`) — **отдельным
  сообщением**, потому что `reply_markup` вмещает либо inline-, либо
  reply-клавиатуру, но не обе. Ставится один раз на чат (KV-ключ `menu:<chatId>`).
- `isArenaCommand` сравнивает текст через `normalizeText()`: нижний регистр +
  вырезание всего кроме букв/цифр/`@` + схлопывание пробелов. Поэтому метка
  кнопки и `/arena@MyBot` распознаются одинаково.
- **Privacy mode**: при включённом Group Privacy Telegram не доставляет боту
  обычный текст группы, поэтому нажатие нижней кнопки бот не увидит. Inline-кнопки
  работают всегда. Выключается только руками: BotFather → `/setprivacy` → Disable.

## Bot API: проверенные факты

- `style` (`primary`/`success`/`danger`) есть у `InlineKeyboardButton` и
  `KeyboardButton`; работает в клиентах после 9 февраля 2026, старые просто без
  заливки. Неизвестные поля Bot API игнорирует, так что слать безопасно.
- `icon_custom_emoji_id` требует юзернейм с Fragment или Telegram Premium у
  владельца бота — **не используем**, эмодзи ставим в `text` кнопки.
- `callback_data` — 1–64 **байта** UTF-8. Текущий формат `a|<chatId>|<arenaId>`
  даёт ~28 байт на супергруппе.

## Состояние

- `arena.js`: KV `ARENAS` (`arena:<chatId>`, TTL 600 с) + fallback в память;
  `menu:<chatId>` с TTL 30 дней. На чат — одна активная арена.
- Тесты: 50 (`npm test`). `webhook.test.js` ищет карточку арены через хелпер
  `arenaCardCall()` (по наличию `inline_keyboard`) — она больше не последнее
  сообщение, после неё идёт подсказка с нижней клавиатурой.
- Проверка визуала без браузера (agent-browser на Windows не работает):
  `test/verify.mjs` (таблица состояний по кадрам + round-trip GIF),
  `test/poses.mjs`, `test/zoom.mjs`, `test/helpers/png.mjs` — свой PNG-энкодер.
